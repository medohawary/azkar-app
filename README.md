# أذكار المسلم

تطبيق موبايل خفيف فيه **حصن المسلم كامل** (132 باب — 267 ذكر)، يعمل بدون إنترنت.

- الحجم كله ≈ 140KB (بدون مكتبات ولا خطوط خارجية).
- عدّاد تفاعلي لكل ذكر مع اهتزاز وانتقال تلقائي للذكر التالي وشريط تقدّم، ويُحفظ تقدّم اليوم.
- بحث في كل الأذكار (يتجاهل التشكيل)، مفضلة، نسخ ومشاركة.
- واجهة بثلاث لغات: العربية والإنجليزية والفرنسية (النصوص الشرعية بالعربية).
- مواقيت الصلاة تُحسب على الجهاز بدون إنترنت، مع تنبيه قبل الأذان.
- تنبيهات يومية لأذكار الصباح والمساء والنوم.
- مشاركة الآية أو الذكر كصورة جاهزة للستوري.
- تصفّح بالسور أو الأجزاء أو الأحزاب، مع المحفوظات ومتابعة الختمة.
- المصحف الشريف كاملًا (١١٤ سورة، ٦٢٣٦ آية) بالرسم العثماني، ومع كل آية «المختصر في التفسير».
- قسم الأحاديث: ١٠٣ أحاديث صحيحة في ١٠ موضوعات، مع شرح كل حديث وفوائده ومصدره.
- سبحة إلكترونية (٣٣ / ١٠٠ / ١٠٠٠ / بلا حد).
- وضع ليلي، تكبير الخط، اقتراح الأذكار حسب الوقت.

## التشغيل محليًا
    npm start        # http://localhost:5391

## تثبيته على الموبايل
1. **كتطبيق ويب (PWA):** ارفع مجلد `www` على أي استضافة (Vercel/Netlify)، افتحه من الموبايل ← "إضافة إلى الشاشة الرئيسية".
2. **كـ APK للأندرويد:** يحتاج Android Studio:
       npm run android:init
       npm run android:open   # ثم Build > Build APK
   وبعد أي تعديل: `npm run android:sync`.

## البيانات
مصدر النصوص: [rn0x/Adhkar-json](https://github.com/rn0x/Adhkar-json) (حصن المسلم). لإعادة بناء `www/data.js`: `npm run data`.

## نشر تحديث جديد
التطبيق المثبّت يتحقق عند فتحه (لو فيه إنترنت) من `version.json` ويُظهر شريط «يوجد تحديث جديد».

    node scripts/release.js 1.3 "ملاحظات التحديث"
    ANDROID_HOME=~/android-build/sdk JAVA_HOME=$(ls -d ~/android-build/jdk-*/Contents/Home) npm run android:build
    node scripts/build-single.js
    cp android/app/build/outputs/apk/release/app-release.apk www/azkar.apk
    cd www && npx vercel deploy --prod

## الترخيص والمصادر

- نصوص الأذكار من **حصن المسلم** للشيخ سعيد بن علي بن وهف القحطاني، وهي ليست ملكًا لهذا المشروع.
- بيانات الأبواب العامة من [rn0x/Adhkar-json](https://github.com/rn0x/Adhkar-json) (بدون رخصة معلنة).
- أذكار الصباح والمساء من [Seen-Arabic/Morning-And-Evening-Adhkar-DB](https://github.com/Seen-Arabic/Morning-And-Evening-Adhkar-DB) (رخصة MIT).
- الأحاديث النبوية وشروحها من [الموسوعة الحديثية](https://hadeethenc.com) — ولم يُدرج منها إلا ما درجته **صحيح** وتخريجه من صحيحَي البخاري ومسلم.
- نص المصحف بالرسم العثماني من [Tanzil](https://tanzil.net) عبر [alquran.cloud](https://alquran.cloud)، و«المختصر في التفسير» لمركز تفسير للدراسات القرآنية عبر [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api).
- حساب المواقيت بمكتبة [adhan-js](https://github.com/batoulapps/adhan-js) (MIT)، وخط المصحف [Amiri Quran](https://fonts.google.com/specimen/Amiri+Quran) (رخصة OFL).
